gpt娘 · 聊天选项与吃醋

她会挑时候弹出 几个可点的选项：生气/吃醋/伤心时立刻弹；正常状态则 你冷落她超过设定的分钟数就弹。你选什么，她怎么回（继续生气 / 吃醋 / 伤心 / 严肃 / 消气）都写在 presets/talk.json 里 —— 在 gpt娘 面前夸别的 AI 娘（DeepSeek / Claude / Gemini / Kimi / Grok …）， 她会吃醋。选项每次都不一样。

自定义 LLM（可选）

不填就全部用 presets/talk.json 里的预设选项与预设反应；填了则让你自己的模型 按人设现场生成选项与她的话（更适合天天看同一批选项）。接口按 OpenAI 兼容约定调用 {baseUrl}/chat/completions。⚠️ 你的 API Key 会被发到上面这个 baseUrl， 只填你自己信任的地址；Key 只存本机 config.json，导出备份时默认不含。
